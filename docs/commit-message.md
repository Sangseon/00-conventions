# Commit Convention

- Planned

```
구상중인 commit message..

<type>: <description>
```

## Type

| Type     | Description              |
| -------- | ------------------------ |
| docs     | 문서 변경                |
| feat     | 기능 추가                |
| fix      | 오류 수정                |
| refactor | 동작 변경 없는 구조 개선 |
| test     | 테스트 추가 및 수정      |

## Examples

```
docs: add repository conventions
feat: add JWT token generation
fix: correct token signature validation
refactor: simplify tokenizer implementation
test: add JWT signature tests
```
